The original documents

Every file the build reads, as published. Gazette copies come from eGazette, the official source; India Code's consolidated reprints are kept as a secondary source to compare against. Where a gazette is a scan, the page images sit beside the machine reading, with the low-confidence lines and every correction marked, so the reading can be checked against the page.
